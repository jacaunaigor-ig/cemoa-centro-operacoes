Sala de monitoramento

Chuva e aviso meteorológico no mesmo mapa, do município ao Brasil. A sala usa dado público e separa o que o pluviômetro leu do que ainda falta uma pessoa confirmar.

Percurso Leitura Código Como rodar

Três recortes, um clique de cada vez

1 · Brasil

Escolher o estado

As 27 unidades da federação entram juntas. O clique abre a malha daquele estado.

2 · Estado

Escolher o município

A malha do IBGE recebe a maior chuva de 24 h entre as estações da cidade.

3 · Município

Ler o pluviômetro

Cada estação mostra o acumulado de 1 h e o de 24 h, com o horário de Brasília.

O que o número significa

0 mm

O pluviômetro respondeu e não acumulou chuva na janela.

Sem leitura

Não há acumulado válido. A sala não herda o valor de outra hora para pintar o mapa.

Aviso do INMET

A mancha vigente entra por cima do mapa. Quem classifica o risco continua sendo o órgão.

Onde isso está no código

Agregação

  • lib/sala-territorio.ts Junta as estações no município e no estado. Separa 0 mm de ausência de leitura.

Consulta

  • app/api/sala/chuva CEMADEN por UF, com cache curto para o recorte nacional.
  • app/api/sala/malha Malha do IBGE para o Brasil ou para os municípios do estado.
  • app/api/sala/avisos Avisos vigentes do INMET filtrados pela UF.

Tela

  • app/sala A rota /sala. O endereço guarda a escala, a UF e o município.

Como rodar

git clone https://github.com/jacaunaigor-ig/cemoa-centro-operacoes.git
cd cemoa-centro-operacoes
npm install
npm run dev

Abra http://127.0.0.1:43127/sala. A sala pública não pede chave. O painel operacional do Amazonas continua na raiz do mesmo projeto.

Uso e limite

Fontes

  • CEMADEN, pluviômetros automáticos
  • INMET, avisos vigentes
  • IBGE, malha territorial
  • OpenStreetMap, mapa de fundo

Para quem

Órgão que acompanha vários municípios, ou equipe privada que precisa dessa leitura sem montar a integração do zero.

Limite

As cores são faixas de leitura. A sala não emite alerta oficial e não substitui a Defesa Civil, o CEMADEN nem o INMET.
